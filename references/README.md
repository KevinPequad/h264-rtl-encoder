# References

This directory is for local reference material used during development.

Expected local references may include:
- H.264 / AVC specification PDFs
- reference implementation notes
- software encoder source trees used as comparison baselines
- architecture scratch material

These files are intentionally kept local and are not committed to the public
repository by default. The expected local H.264 spec path used by the project
docs is:

- `references/itu/T-REC-H.264-202408-I.pdf`

Expected local software reference baseline:

- `references/software/x264/`
